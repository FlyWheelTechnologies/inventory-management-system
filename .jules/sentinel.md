## 2024-05-24 - Hardcoded Secrets in Source Code
**Vulnerability:** A hardcoded `JWT_SECRET` and a hardcoded initial `admin123` password were found directly in `server/index.js`.
**Learning:** Hardcoding secrets like a JWT signing key exposes all sessions to attackers who gain access to the source code. Storing initial administrative passwords in plain text can lead to default credential exploitation. Replacing static initialization passwords with dynamically generated crypto keys avoids predictable credentials, but one must ensure dynamically generated secrets are not used for JWTs without persistence to prevent mass session invalidation across server restarts.
**Prevention:** Always enforce the explicit injection of secrets via environment variables in production. For default accounts, use dynamic generation and log the credential at initialization, or require an initial password via environment configuration, and ensure developers receive a fatal error when critical security configurations are missing.
