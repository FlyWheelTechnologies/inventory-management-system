## 2024-05-24 - [Unmemoized Heavy Calculations Blocking Modal Input]
**Learning:** Derived state calculations using large array operations (e.g., `filter`, `reduce`, `sort` over `sales` and `products`) placed directly inside the React component body will re-execute synchronously on every render. If an unrelated state update occurs frequently (like typing into a text input inside a modal, updating state on every keystroke), these expensive calculations cause significant UI thread blocking and severe input lag.
**Action:** Always wrap heavy data aggregations and transformations (especially those with sorting and filtering) in a `useMemo` hook, defining dependencies properly. This ensures they only run when the underlying data changes, not during unrelated UI state changes like modal interactions or form input.
