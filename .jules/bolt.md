## 2024-05-25 - React Component Derived State Memoization
**Learning:** Performing multiple heavy `filter` and `reduce` operations on large arrays (e.g., `sales`, `products`) directly in the component body blocks the UI thread. This becomes a severe bottleneck when the component also handles frequent local state updates, such as controlled inputs (e.g., typing in a deposit modal), leading to noticeable input lag. This codebase tends to perform data grouping and summarization on the client-side.
**Action:** Always wrap heavy derived state calculations (e.g., sorting, reducing, or filtering large datasets) inside a `useMemo` hook. This ensures these expensive operations are only recomputed when their source data dependencies change, preventing them from running on every local state keystroke and keeping the UI responsive.
